# PHP 设计模式划分摘要

### 一、创建型模式 (Creational Patterns) - 5种
**核心目的：** 封装对象的创建过程，将系统与它的对象创建、组合、表示方式解耦。

| 模式名称 | 核心思想 | PHP 应用场景 |
| :--- | :--- | :--- |
| **单例模式 (Singleton)** | 保证一个类仅有一个实例，并提供全局访问点 | 数据库连接、日志记录器、应用配置、缓存对象 |
| **工厂方法模式 (Factory Method)** | 定义创建对象的接口，让子类决定实例化哪个类 | 支付网关（支付宝、微信）、日志记录器（文件、数据库） |
| **抽象工厂模式 (Abstract Factory)** | 创建相关或依赖对象的家族，而不需要指定具体类 | UI 主题套件、数据库系列组件（MySQL、PostgreSQL连接器） |
| **建造者模式 (Builder)** | 将复杂对象的构建与其表示分离，允许同样构建过程创建不同表示 | SQL 查询构建器、邮件对象构建、复杂订单生成 |
| **原型模式 (Prototype)** | 通过复制现有对象来创建新对象，而不是新建 | 避免昂贵初始化开销，游戏对象复制，配置模板复制 |

---

### 二、结构型模式 (Structural Patterns) - 7种
**核心目的：** 关注类和对象的组合，形成更大、更复杂的结构。

| 模式名称 | 核心思想 | PHP 应用场景 |
| :--- | :--- | :--- |
| **适配器模式 (Adapter)** | 将一个类的接口转换成客户希望的另一个接口 | 集成第三方库、兼容老旧接口、统一不同类的接口 |
| **桥接模式 (Bridge)** | 将抽象部分与实现部分分离，使它们可以独立变化 | 图形绘制（形状+颜色）、消息发送（消息类型+发送渠道） |
| **组合模式 (Composite)** | 将对象组合成树形结构以表示"部分-整体"的层次结构 | 文件系统、菜单树、组织架构、表单字段组合 |
| **装饰器模式 (Decorator)** | 动态地给对象添加额外的职责，是继承的替代方案 | Laravel 中间件、流处理器加密压缩、功能增强 |
| **外观模式 (Facade)** | 为子系统中的一组接口提供一个一致的简化接口 | Laravel Facades、复杂API的简化封装、子系统入口 |
| **享元模式 (Flyweight)** | 运用共享技术有效支持大量细粒度对象 | 文本编辑器字符对象、游戏中的大量重复元素 |
| **代理模式 (Proxy)** | 为其他对象提供一种代理以控制对这个对象的访问 | 延迟加载（ORM关联）、权限控制、缓存代理、远程代理 |

---

### 三、行为型模式 (Behavioral Patterns) - 11种
**核心目的：** 关注对象之间的职责分配、通信和算法。

| 模式名称 | 核心思想 | PHP 应用场景 |
| :--- | :--- | :--- |
| **责任链模式 (Chain of Responsibility)** | 让多个对象都有机会处理请求，形成处理链 | Laravel 中间件、审批流程、异常处理链 |
| **命令模式 (Command)** | 将请求封装为对象，支持参数化、队列、日志、撤销等 | 任务队列、可撤销操作、GUI按钮命令 |
| **解释器模式 (Interpreter)** | 给定一个语言，定义其文法表示，并定义解释器 | 简单语法解析、数学表达式计算、DSL解释 |
| **迭代器模式 (Iterator)** | 提供一种方法顺序访问聚合对象中的各个元素 | PHP 原生迭代器、集合遍历、文件行读取 |
| **中介者模式 (Mediator)** | 用一个中介对象来封装一系列的对象交互 | 聊天室、MVC控制器、组件协调器 |
| **备忘录模式 (Memento)** | 在不破坏封装的前提下捕获并外部化对象的内部状态 | 撤销/重做功能、游戏存档、状态回滚 |
| **观察者模式 (Observer)** | 定义对象间的一对多依赖关系，状态变化时自动通知 | Laravel Event/Listener、消息订阅、状态监听 |
| **状态模式 (State)** | 允许对象在内部状态改变时改变其行为 | 订单状态流转、游戏角色状态、工作流引擎 |
| **策略模式 (Strategy)** | 定义一系列算法，封装它们并使它们可互相替换 | 支付策略、排序算法、折扣计算策略 |
| **模板方法模式 (Template Method)** | 定义算法骨架，将一些步骤延迟到子类中实现 | 框架基类、数据迁移模板、业务流程模板 |
| **访问者模式 (Visitor)** | 表示一个作用于某对象结构中的各元素的操作 | 抽象语法树操作、报表生成、复杂结构处理 |
| **空对象模式 (Null Object)** | 用空对象代替 null 值，避免空值检查 | 默认值处理、空用户对象、默认响应处理 |

## 快速记忆口诀

**创建型（5）：单原工建抽**
- 单(单例) 原(原型) 工(工厂方法) 建(建造者) 抽(抽象工厂)

**结构型（7）：适代享外组桥代**
- 适(适配器) 代(代理) 享(享元) 外(外观) 组(组合) 桥(桥接) 代(装饰器)

**行为型（11）：责命解迭中备观状策模访空**
- 责(责任链) 命(命令) 解(解释器) 迭(迭代器) 中(中介者) 备(备忘录) 观(观察者) 状(状态) 策(策略) 模(模板方法) 访(访问者) 空(空对象)

## 使用建议

1.  **不要为了用模式而用模式**，优先保持代码简单
2.  **理解每个模式的适用场景**，避免过度设计
3.  **PHP 中常用模式**：单例、工厂、观察者、策略、装饰器、适配器
4.  **框架内置模式**：Laravel 大量使用容器、观察者、工厂、装饰器等模式

这个摘要可以帮助你快速回顾和理解各种设计模式的核心概念和适用场景。
