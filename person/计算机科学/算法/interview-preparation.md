### 算法面试准备架构解析

算法面试是评估计算机科学候选人问题解决能力和技术深度的关键环节。以下从知识体系、解题策略到实战技巧进行全面解析。

#### 1. 核心知识体系

##### 1.1 数据结构精通
**基础结构**：
- 数组：随机访问 \(O(1)\)，插入删除 \(O(n)\)
- 链表：顺序访问 \(O(n)\)，插入删除 \(O(1)\)
- 哈希表：平均 \(O(1)\) 访问，冲突处理

**树结构**：
- 二叉树：遍历（前序、中序、后序）
- BST：搜索 \(O(h)\)，平衡树保证 \(h = O(\log n)\)
- 堆：优先队列，插入删除 \(O(\log n)\)

**图结构**：
- 表示：邻接矩阵 \(O(1)\) 查询，\(O(n^2)\) 空间
- 邻接表： \(O(deg(v))\) 查询，\(O(n+m)\) 空间

##### 1.2 算法范式掌握
**分治策略**：
- 归并排序： \(T(n) = 2T(n/2) + O(n)\)
- 快速排序：期望 \(O(n\log n)\)，最坏 \(O(n^2)\)

**动态规划**：
状态定义 + 转移方程
\[
dp[i] = \min/\max\{dp[j] + cost(j,i)\}
\]

**贪心算法**：
局部最优 → 全局最优
需证明贪心选择性质

#### 2. 解题方法论

##### 2.1 问题分析框架
**复杂度估算**：
输入规模 \(n\) 与预期解法匹配
- \(n \leq 10^6\): \(O(n)\) 或 \(O(n\log n)\)
- \(n \leq 10^3\): \(O(n^2)\) 可接受

**模式识别**：
- 排序数组+查找 → 二分搜索
- 最近相关元素 → 栈/单调栈
- 子数组问题 → 滑动窗口/前缀和

##### 2.2 沟通策略
**明确问题**：
- 输入输出规范
- 边界情况确认
- 假设澄清

**思路阐述**：
- 暴力解法首先说明
- 逐步优化思路
- 复杂度分析同步进行

#### 3. 代码实现技巧

##### 3.1 编码规范
**可读性优先**：
```python
# Good: 清晰命名和结构
def find_max_subarray(arr):
    max_sum = current_sum = arr[0]
    for num in arr[1:]:
        current_sum = max(num, current_sum + num)
        max_sum = max(max_sum, current_sum)
    return max_sum

# Bad: 隐晦难懂
def f(a):
    m=c=a[0]
    for x in a[1:]:
        c=max(x,c+x)
        m=max(m,c)
    return m
```

**错误处理**：
- 空输入检查
- 边界条件处理
- 断言关键不变量

##### 3.2 测试用例设计
**典型场景**：
- 正常情况
- 边界值：空、单元素、极值
- 错误输入：非法值、越界

**覆盖策略**：
- 路径覆盖：执行所有分支
- 边界覆盖：测试边界条件

#### 4. 复杂度分析能力

##### 4.1 时间复杂度
**递归分析**：
主定理求解递推式：
\[
T(n) = aT(n/b) + f(n)
\]

**平摊分析**：
序列操作的平均成本
示例：动态数组插入 \(O(1)\) 平摊时间

##### 4.2 空间复杂度
**显式空间**：数据结构存储
**隐式空间**：递归调用栈深度

#### 5. 常见问题模式

##### 5.1 字符串处理
**模式匹配**：
- KMP算法： \(O(n+m)\)
- Rabin-Karp：滚动哈希

**回文问题**：
- 中心扩展： \(O(n^2)\)
- Manacher算法： \(O(n)\)

##### 5.2 树相关问题
**遍历变种**：
- 层级遍历：BFS + 队列
- 视图问题：记录每层第一个/最后一个

**LCA问题**：
- 二叉树：递归查找
- 一般树：倍增法预处理

##### 5.3 图算法应用
**最短路径**：
- Dijkstra：非负权，\(O((V+E)\log V)\)
- Bellman-Ford：负权检测，\(O(VE)\)

**拓扑排序**：
Kahn算法：不断移除入度0节点
