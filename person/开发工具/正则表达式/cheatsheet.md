# 正则表达式速查表

> 本速查表提供了正则表达式核心语法的快速参考，包括元字符、量词、字符类、分组等常用语法元素。

## 元字符（Metacharacters）

### 基本元字符

| 字符 | 描述 | 示例 |
|------|------|------|
| `.` | 匹配除换行符外的任意字符 | `a.c` → "abc", "a1c" |
| `^` | 匹配字符串开始 | `^abc` → "abc"开头 |
| `$` | 匹配字符串结束 | `abc$` → "abc"结尾 |
| `\` | 转义特殊字符 | `\.` → 匹配点号 |
| `\|` | 或操作 | `a\|b` → "a" 或 "b" |
| `[]` | 字符类 | `[abc]` → "a", "b", 或 "c" |
| `()` | 分组 | `(abc)+` → "abc", "abcabc" |

### 预定义字符类

| 字符 | 等价 | 描述 |
|------|------|------|
| `\d` | `[0-9]` | 数字字符 |
| `\D` | `[^0-9]` | 非数字字符 |
| `\w` | `[a-zA-Z0-9_]` | 单词字符 |
| `\W` | `[^a-zA-Z0-9_]` | 非单词字符 |
| `\s` | `[ \t\n\r\f\v]` | 空白字符 |
| `\S` | `[^ \t\n\r\f\v]` | 非空白字符 |

## 量词（Quantifiers）

### 基本量词

| 量词 | 描述 | 示例 |
|------|------|------|
| `*` | 零次或多次 | `a*` → "", "a", "aa" |
| `+` | 一次或多次 | `a+` → "a", "aa" |
| `?` | 零次或一次 | `a?` → "", "a" |
| `{n}` | 恰好n次 | `a{3}` → "aaa" |
| `{n,}` | 至少n次 | `a{2,}` → "aa", "aaa" |
| `{n,m}` | n到m次 | `a{2,4}` → "aa", "aaa", "aaaa" |

### 贪婪与非贪婪

| 模式 | 描述 | 示例 |
|------|------|------|
| `*` | 贪婪匹配 | `.*` 匹配尽可能多 |
| `*?` | 非贪婪匹配 | `.*?` 匹配尽可能少 |
| `+?` | 非贪婪匹配 | `.+?` 匹配尽可能少 |
| `??` | 非贪婪匹配 | `a??` 优先匹配零次 |

## 字符类（Character Classes）

### 基本字符类

| 模式 | 描述 | 示例 |
|------|------|------|
| `[abc]` | 匹配a、b或c | `[aeiou]` → 元音字母 |
| `[^abc]` | 匹配除a、b、c外的字符 | `[^0-9]` → 非数字 |
| `[a-z]` | 小写字母 | `[a-z]` → a到z |
| `[A-Z]` | 大写字母 | `[A-Z]` → A到Z |
| `[0-9]` | 数字 | `[0-9]` → 0到9 |
| `[a-zA-Z]` | 所有字母 | `[a-zA-Z]` → 所有字母 |

### 特殊字符类

| 模式 | 描述 | 示例 |
|------|------|------|
| `[[:alpha:]]` | 字母字符 | 等价于 `[a-zA-Z]` |
| `[[:digit:]]` | 数字字符 | 等价于 `[0-9]` |
| `[[:alnum:]]` | 字母数字字符 | `[a-zA-Z0-9]` |
| `[[:space:]]` | 空白字符 | 空格、制表符等 |
| `[[:punct:]]` | 标点符号 | `. , ! ?` 等 |

## 分组与捕获（Grouping and Capturing）

### 分组类型

| 模式 | 描述 | 示例 |
|------|------|------|
| `(pattern)` | 捕获分组 | `(abc)` 捕获 "abc" |
| `(?:pattern)` | 非捕获分组 | `(?:abc)` 不捕获 |
| `(?<name>pattern)` | 命名捕获组 | `(?<year>\d{4})` |
| `(?=pattern)` | 正向先行断言 | `a(?=b)` 后面是b的a |
| `(?!pattern)` | 负向先行断言 | `a(?!b)` 后面不是b的a |
| `(?<=pattern)` | 正向后行断言 | `(?<=a)b` 前面是a的b |
| `(?<!pattern)` | 负向后行断言 | `(?<!a)b` 前面不是a的b |

### 反向引用

| 模式 | 描述 | 示例 |
|------|------|------|
| `\1` | 引用第一个捕获组 | `(a)\1` → "aa" |
| `\2` | 引用第二个捕获组 | `(a)(b)\2\1` → "abba" |
| `\k<name>` | 引用命名捕获组 | `(?<char>a)\k<char>` → "aa" |

## 边界匹配（Boundary Matchers）

### 边界类型

| 边界 | 描述 | 示例 |
|------|------|------|
| `^` | 行/字符串开始 | `^abc` |
| `$` | 行/字符串结束 | `abc$` |
| `\b` | 单词边界 | `\bword\b` → 独立单词 |
| `\B` | 非单词边界 | `\Bword\B` → "swordfish"中的"word" |
| `\A` | 输入开始 | `\Aabc` |
| `\Z` | 输入结束 | `abc\Z` |
| `\z` | 输入绝对结束 | `abc\z` |

## 修饰符（Modifiers/Flags）

### 常用修饰符

| 修饰符 | 描述 | 示例 |
|------|------|------|
| `i` | 忽略大小写 | `/abc/i` → "ABC", "abc" |
| `g` | 全局匹配 | 匹配所有而非第一个 |
| `m` | 多行模式 | `^`和`$`匹配每行 |
| `s` | 单行模式 | `.`匹配包括换行符 |
| `u` | Unicode模式 | 支持Unicode属性 |
| `x` | 注释模式 | 忽略空白和注释 |

## 常用模式示例

### 数据验证

| 用途 | 模式 | 说明 |
|------|------|------|

| 用途 | 模式 | 说明 |

## 性能优化提示

### 优化技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| 具体化 | 使用具体字符类代替通配符 | `[^abc]*abc` 代替 `.*abc` |
| 非贪婪 | 使用非贪婪匹配避免过度匹配 | `.*?` 代替 `.*` |
| 锚点 | 使用锚点限制匹配范围 | `^pattern$` |
| 预编译 | 预编译重复使用的正则表达式 | `const regex = /pattern/;` |
| 避免回溯 | 避免嵌套量词和复杂选择 | `a+b` 代替 `(a+)+b` |

### 危险模式

| 危险模式 | 问题 | 安全替代 |
|----------|------|----------|
| `(a+)+b` | 灾难性回溯 | `a+b` |
| `(a\|aa)+b` | 指数级复杂度 | `a+b` |
| `.*a.*b.*c` | 过度回溯 | `[^a]*a[^b]*b[^c]*c` |

## 实用函数

### JavaScript 实用函数

```javascript
// 转义正则特殊字符
function escapeRegex(text) {
    return text.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
}

// 验证正则表达式语法
function isValidRegex(pattern) {
    try {
        new RegExp(pattern);
        return true;
    } catch (e) {
        return false;
    }
}

// 提取所有匹配
function extractAll(pattern, text) {
    const regex = new RegExp(pattern, 'g');
    const matches = [];
    let match;
    
    while ((match = regex.exec(text)) !== null) {
        matches.push(match[0]);
    }
    
    return matches;
}
```

### Python 实用函数

```python
import re

def extract_emails(text):
    """提取所有邮箱地址"""
    pattern = r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b'
    return re.findall(pattern, text)

def validate_pattern(pattern):
    """验证正则表达式语法"""
    try:
        re.compile(pattern)
        return True
    except re.error:
        return False
```

## 总结

本速查表涵盖了正则表达式的核心概念：

- **元字符**：基础构建块，如 `.`, `^`, `$`, `\`
- **量词**：控制重复次数，如 `*`, `+`, `?`, `{}`
- **字符类**：定义字符集合，如 `[abc]`, `\d`, `\w`
- **分组**：组织模式，如 `()`, `(?:)`, `(?<name>)`
- **断言**：条件匹配，如 `(?=)`, `(?<=)`
- **修饰符**：改变匹配行为，如 `i`, `g`, `m`

> 提示：正则表达式需要实践才能掌握。建议从简单模式开始，逐步构建复杂模式，并使用在线工具进行测试和调试。记住考虑性能和可读性，避免过度复杂的正则表达式。
