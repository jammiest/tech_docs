### 2. 记忆技巧
```markdown
# 正则表达式记忆口诀

**基础元字符**：
- `.` 点号匹配任意字符（除换行）
- `\d` 数字，`\D` 非数字
- `\w` 单词字符，`\W` 非单词字符
- `\s` 空白字符，`\S` 非空白字符

**量词记忆**：
- `*` 零或多个（贪婪）
- `+` 一或多个（贪婪）  
- `?` 零或一个（贪婪）
- `{n}` 恰好n次
- `{n,}` 至少n次
- `{n,m}` n到m次

**锚点记忆**：
- `^` 字符串开始
- `$` 字符串结束
- `\b` 单词边界
- `\B` 非单词边界
```

### 3. 调试技巧
```python
# 正则表达式调试流程
def debug_regex(pattern, text):
    print(f"测试模式: {pattern}")
    print(f"测试文本: {text}")
    
    try:
        import re
        match = re.search(pattern, text)
        if match:
            print("✅ 匹配成功")
            print(f"匹配内容: {match.group()}")
            print(f"匹配位置: {match.start()} - {match.end()}")
            if match.groups():
                print(f"捕获组: {match.groups()}")
        else:
            print("❌ 匹配失败")
            
    except re.error as e:
        print(f"❌ 模式错误: {e}")
    
    print("-" * 50)

# 示例使用
debug_regex(r'\d{3}-\d{2}-\d{4}', 'SSN: 123-45-6789')
```
